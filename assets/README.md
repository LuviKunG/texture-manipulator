# App Icons

This folder contains the application icons for different platforms:

- `icon.ico` - Windows icon (256x256 or multi-size recommended)
- `icon.icns` - macOS icon (512x512 recommended)
- `icon.png` - Linux icon (512x512 recommended)

## How to create icons

### Windows (.ico)

- Use an online converter or tools like GIMP, Paint.NET, or IcoFX
- Recommended sizes: 16x16, 32x32, 48x48, 64x64, 128x128, 256x256
- Save as .ico format

### macOS (.icns)

- Use Icon Composer (part of Xcode) or online converters
- Start with a 1024x1024 PNG image
- Use `iconutil` command or online tools to convert to .icns

### Linux (.png)

- Use a 512x512 PNG image
- Ensure transparency is preserved if needed
